# Handoffs (local working notes; gitignored)

Start here, then read only the area your task needs.

| Folder | What it covers |
|---|---|
| `overview/` | Priorities across areas, key decisions, an index of what was delivered |

**Same files in every folder** (delete the ones an area doesn't need):
`README.md` status, next step, read order, last session · `01-feature.md` what and why, acceptance ·
`02-code-map.md` where things live · `03-open-issues.md` open work (pointers) and gotchas ·
`04-plan.md` next steps and how work runs · `05-questions.md` decisions waiting · `06-delivered.md`
finished work (keeps READMEs short). Named extras (e.g. `ops.md`, `decisions.md`) are fine.

**Rules:** the issue tracker, ADRs and docs are the source of truth; handoffs point to them. Absolute
dates. No secrets or client data. Update the affected areas before a PR and at the end of a session.
